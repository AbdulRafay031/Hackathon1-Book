Module 1: The Robotic Nervous System (ROS 2)

Target audience:
AI/CS students with Python knowledge entering Physical AI and humanoid robotics

Focus:
ROS 2 as the core middleware for humanoid robot control, communication, and structure, with Python-based AI agent integration

Chapters:
1. ROS 2 Fundamentals
   - Middleware concept, ROS 2 role, ROS 1 vs ROS 2

2. Communication Model
   - Nodes, Topics, Services, Actions, message flow

3. Python Agents with rclpy
   - Creating nodes, pub/sub, bridging AI logic to controllers

4. Humanoid Description with URDF
   - Links, joints, kinematics, common modeling pitfalls

Success criteria:
- Reader understands ROS 2 architecture
- Reader can write basic rclpy nodes
- Reader can explain AI-to-ROS integration
- Reader can read and modify humanoid URDFs

Constraints:
- Length: 1,500–2,000 words
- Format: Markdown (Docusaurus)
- Code: Minimal, executable
- Sources: Official ROS 2 and URDF documentation

Not building:
- Installation guides
- Hardware drivers
- Deep DDS internals
